# Запасная копия браузера Camoufox для Маркетингового разведчика

Здесь лежат **неизменённые** сборки браузера [Camoufox](https://camoufox.com) из форка
[coryking/camoufox](https://github.com/coryking/camoufox), выпуск
[`v142.0.1-fork.26`](https://github.com/coryking/camoufox/releases/tag/v142.0.1-fork.26). Исходный репозиторий
`daijro/camoufox` с GitHub удалён, поэтому копия хранится отдельно, чтобы сборка разведчика скачивала браузер без входа в GitHub.

Исходный код браузера: https://github.com/coryking/camoufox. Лицензия: MPL-2.0 (см. `LICENSE`, также https://www.mozilla.org/MPL/2.0/).
Архивы не пересобирались и не менялись: имена файлов и суммы совпадают с исходным выпуском.
